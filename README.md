# Clinical Data Management Practice Project

## Clinical Trial Data Review & Query Management

A self-directed Clinical Data Management (CDM) practice project based on a simulated Phase II randomized, double-blind, placebo-controlled clinical trial in migraine.

The project demonstrates a structured clinical data management workflow using simulated clinical trial data and Microsoft Excel.

---

## Project Overview

**Study ID:** CDM-MIG-001  
**Study Phase:** Phase II  
**Study Design:** Randomized, Double-Blind, Placebo-Controlled, Parallel-Group  
**Indication:** Migraine  
**Number of Subjects:** 20  
**Study Duration:** 12 Weeks  
**Data Management Tool:** Microsoft Excel  
**Project Type:** Self-Directed Practice Project

The project was developed to practice the basic workflow involved in clinical data review, discrepancy identification, query management, data correction, quality control, and final data review.

---

## Project Objective

The objective of this project was to gain practical exposure to a structured Clinical Data Management workflow by working with simulated clinical trial data.

The project focused on:

- Reviewing clinical trial data for completeness and consistency
- Identifying missing, invalid, or inconsistent data
- Applying predefined data validation checks
- Documenting discrepancies in a validation log
- Creating and tracking data queries
- Recording simulated site responses
- Documenting data corrections
- Performing quality control checks
- Conducting a final review of cleaned data
- Maintaining traceability throughout the data review process

## Clinical Data Management Workflow

The project follows the workflow below:

**Protocol → CRF Design → Raw Data → Data Validation → Query Management → Site Response → Data Correction → QC → Final Data Review**

### 1. Protocol Review

Reviewed the simulated study protocol to understand the study design, subject population, treatment groups, visits, and required data collection.

### 2. CRF Design

Created a structured Case Report Form (CRF) design covering key clinical data domains required for the simulated study.

### 3. Raw Data Preparation

Created simulated subject-level clinical trial data for 20 subjects using Microsoft Excel.

### 4. Data Validation

Performed predefined checks to identify missing, invalid, or inconsistent data entries.

### 5. Query Management

Documented identified discrepancies in a query log and recorded simulated site responses and resolutions.

### 6. Data Cleaning

Documented confirmed corrections in a data cleaning log while maintaining traceability of the original issue and corrected value.

### 7. Quality Control

Performed QC checks on corrected data to confirm that documented corrections were appropriately addressed.

### 8. Final Data Review

Reviewed the major clinical data domains after completion of cleaning and QC checks.

## Project Limitations

This is a self-directed educational practice project using simulated clinical trial data.

The project does not represent professional clinical trial experience and was not performed for a sponsor, CRO, investigator site, or regulatory submission.

The site responses, queries, corrections, and QC activities were created for learning and demonstration purposes.

No real patient data or Protected Health Information (PHI) was used.
